## ✨ Features

- TypeScript-based Docusaurus (classic preset) configuration
- Docs-only layout (blog plugin disabled)
- Autogenerated sidebar from the `docs` folder structure
- Dark mode that follows the system preference
- GitHub Actions workflow for GitHub Pages deployment
- Pre-built documentation scaffolds: context, requirements, planning, architecture, decisions, and prototype

## 📂 Documentation Structure

```
docs/
├── intro.md                 # Template guide and adoption steps
├── 00-context/              # Project overview, personas, glossary, open questions, out of scope
├── 01-requirements/         # Feature map + per-feature requirement template
├── 02-planning/             # Phased roadmap and role mapping
├── 03-architecture/         # Core, API, database, diagrams, ops, security
├── 04-decisions/            # ADR decision log + ADR template
└── 05-prototype/            # Prototype brief, design direction, Pencil files
```

Work items (epics, user stories) live in **Jira** for production projects. The
`examples/work-items/` folder at the repo root contains a filled-in reference
instance — safe to delete when starting a new project.

## 🚀 Getting Started

### ⚙️ Prerequisites

- Node.js >= 20
- npm >= 10
- Git

### 💾 Installation

```sh
# Clone the repository
git clone https://github.com/your-org/template-docs.git
cd template-docs

# Install dependencies
npm install
```

### 🏃 Running Locally

```sh
# Start the dev server with hot reload
npm start
```

This opens the site at **http://localhost:3000**. The server watches for file changes and reloads automatically.

| Command | Description |
|---|---|
| `npm start` | Start the dev server (hot reload) |
| `npm run build` | Build for production into `build/` |
| `npm run serve` | Serve the production build locally |
| `npm run typecheck` | Run the TypeScript compiler check |
| `npm run clear` | Clear the Docusaurus cache |

## 🛠️ Template Setup Checklist

Before deploying your own site based on this template, replace the placeholder values:

1. In `docusaurus.config.ts`:
   - `title`, `tagline` — your project name and description
   - `url` — production URL, e.g. `https://<organizationName>.github.io`
   - `baseUrl` — use `/` for custom domains or user/org sites, `/<projectName>/` for GitHub Pages project sites
   - `organizationName`, `projectName` — your GitHub org/user and repository name
   - `editUrl` — point to your repository to enable "Edit this page" links
   - Navbar and footer links — your GitHub repository and community links
2. In this `README.md` — replace the badge URL and repository links
3. Fill in every `[Project Name]` and `YYYY-MM-DD` placeholder in `docs/` using search-and-replace
4. Replace `static/img/logo.svg` and `static/img/favicon.ico` with your branding
5. Delete `examples/` if you don't need the reference work items
6. For GitHub Pages: in the repository settings, set **Settings → Pages → Source** to **GitHub Actions**
