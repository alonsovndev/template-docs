# Project Structure

This template follows the standard Docusaurus layout:

```text
template-docs
├── docs                    # Markdown documentation files
│   ├── intro.md
│   └── getting-started     # Category folder (with _category_.json)
├── src
│   ├── components          # Reusable React components
│   ├── css                 # Custom CSS overrides
│   └── pages               # Standalone site pages
├── static                  # Static assets, copied to the build root
├── docusaurus.config.ts    # Site configuration
├── sidebars.ts             # Sidebar definition (autogenerated)
└── package.json
```

## Key files

| File | Purpose |
|---|---|
| `docusaurus.config.ts` | Site title, URLs, navbar, footer, and plugin options |
| `sidebars.ts` | Sidebar definition; autogenerated from the `docs` folder by default |
| `_category_.json` | Per-category metadata: label, position, and generated index page |
