# Adding Content

## Add a document

Create a Markdown file anywhere under `docs/`. The sidebar is autogenerated from the folder structure, so no manual sidebar registration is needed.

```md
---
sidebar_position: 3
---

# My New Document

Write your content here.
```

## Add a category

Create a folder under `docs/` with a `_category_.json` file:

```json
{
  "label": "My Category",
  "position": 3,
  "link": {
    "type": "generated-index",
    "description": "A short description shown on the category index page."
  }
}
```

## Add a page

Any React (`.tsx`) or Markdown (`.mdx`) file under `src/pages/` becomes a standalone page.

## Site configuration

Update the placeholder values in `docusaurus.config.ts` before deploying:

- `url` and `baseUrl`
- `organizationName` and `projectName` (GitHub Pages deployment)
- `editUrl` (enables the "Edit this page" links)
