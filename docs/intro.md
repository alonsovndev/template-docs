# Introduction

Welcome to **Template Docs**, a documentation site template built with [Docusaurus](https://docusaurus.io/).

Use this template as the starting point for your project's documentation. It ships with a minimal, working structure that you can extend with your own content.

## What's included

- TypeScript-based Docusaurus configuration
- Autogenerated sidebar from the `docs` folder structure
- Documentation categories with generated index pages
- Dark mode that follows the user's system preference
- GitHub Actions workflow to deploy to GitHub Pages

Head over to the [Getting Started](/docs/category/getting-started) section to learn how to customize this template for your project.
