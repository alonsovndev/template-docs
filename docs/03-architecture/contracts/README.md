# Interfaces and Data Contracts

## Overview

Contract domain documents: the design standards every interface follows and the
contract catalog itself. Not every project is a REST API — this domain covers
whatever kind of interface the project exposes: REST, gRPC/RPC, CLI, event/message
schemas, or a library/SDK's public interface.

## Documents

| Document | Description |
| -------- | ----------- |
| [contract-design-standards.md](./contract-design-standards.md) | Naming, versioning, error handling, and format conventions for the chosen contract type(s) |
| [contract-catalog.md](./contract-catalog.md) | Catalog of interfaces/operations and shared schemas |
